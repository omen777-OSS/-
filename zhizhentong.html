使用指南

🏥 智诊通是什么

AI 健康预问诊助手，通过对话了解您的不适，给出风险分层和就医建议。不做诊断、不开处方，急症请立即拨打 120。

💬 如何使用
  1. 在输入框描述您最不舒服的地方，或点击下方快捷选项
  2. 根据 AI 的追问，依次回答持续时间、难受程度、伴随症状等
  3. 问诊完成后，页面下方会生成风险结果卡，包含风险等级、健康建议和推荐科室
  4. 如出现胸痛、呼吸困难、意识不清等急症，系统会立即拦截并提示拨打 120
📱 手机端 / 其他电脑使用

为保证大模型 API 在任何设备上稳定可用，推荐使用本地代理服务启动：

  1. 双击文件夹中的 启动智诊通.bat
  2. 首次运行会提示输入 API 密钥，粘贴后回车
  3. 浏览器会自动打开页面，手机/其他电脑连接同一 WiFi 后，访问窗口中显示的局域网地址即可
💡 代理模式下 API 密钥保存在服务端，前端不接触密钥，无 CORS 跨域问题，手机/电脑/平板都能稳定使用。开会前提前启动服务即可。
🌐 让任何人在任何地方使用（云端部署）

如果需要分享给客户/患者/同事在任何地方用手机打开，需要部署到云端：

  1. 把所有文件上传到 GitHub 仓库
  2. 在 Render.com（免费）用 GitHub 账号登录
  3. New → Web Service → 选择你的仓库
  4. 环境变量添加 LLM_API_KEY = 你的 DeepSeek 密钥
  5. 部署完成后得到一个 https://xxx.onrender.com 网址，任何人手机打开即用
📖 详细图文步骤见随附的 部署指南.md 文件。Render 免费版 15 分钟无访问会休眠，首次打开需等 10-30 秒。
⚙️ 大模型配置

支持所有 OpenAI 兼容接口，推荐：

  • DeepSeek：接口 https://api.deepseek.com/v1，模型 deepseek-chat
  • OpenAI：接口 https://api.openai.com/v1，模型 gpt-4o-mini

在设置中点对应预设按钮可一键填入，然后粘贴密钥、测试连接、保存即可。

⚠️ 重要提示
  • 本工具仅供健康咨询与导诊参考，不构成诊断或处方
  • 急症（胸痛、呼吸困难、意识不清、大出血等）请立即拨打 120
  • 请勿在对话中输入姓名、身份证号、银行卡号等敏感个人信息
